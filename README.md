# Early Years, Together

A four-page static website for Assignment 2: Families in Transitions.

## Pages
- `index.html` — Early childhood education in Canada
- `partnerships.html` — Ways to involve families in ECE
- `transitions.html` — Issues facing families through transitions
- `about.html` — Student details and references

Open `index.html` locally, or visit the GitHub Pages site after deployment. The pages use responsive CSS and plain JavaScript; no build step is required.
